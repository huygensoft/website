# Huygensoft website

The Huygensoft website is a Vite + React single-page application. It uses a light/dark liquid-glass design system, responsive layouts, browser-language detection with a persisted language choice, and locale routes for English, Italian, Dutch, Yoruba, Igbo, French, German, Spanish, Portuguese, Arabic and Simplified Chinese.

The source lives in `src/`; `static/` contains deployable static assets; `public/` is generated by the build and is the Firebase Hosting directory. Do not edit `public/` by hand.

## Local development

```powershell
npm install
npm run dev
```

The site opens at `http://localhost:5173`. In development, Vite proxies `/api` to `http://localhost:5209`, so run the companion API from `../websiteBackend` if you want to exercise the contact form.

```powershell
Set-Location ..\websiteBackend
dotnet run --launch-profile http
```

## Checks and production build

```powershell
npm run typecheck
npm run lint
npm test
npm run build
```

`npm run build` removes any previous `public/` contents and creates the Firebase deployment artifact. The GitHub Firebase workflows install dependencies and run this build before preview or live deployment.

## Contact API configuration

The application never embeds a private key or contact-service secret. Before production deployment, supply the independently hosted API base URL:

```powershell
$env:VITE_CONTACT_API_BASE_URL = 'https://huygensoftsitebackend-crg8d6c8fnhpe4e3.westeurope-01.azurewebsites.net'
npm run build
```

Alternatively, set the public `contactApiBaseUrl` in `static/runtime-config.js` before building. It is currently configured for the Azure App Service API. Deploy the API artifact and its production settings before deploying this frontend build, then verify `/health` and CORS from each site domain. See `../websiteBackend/README.md` for its server-side configuration, persistence, and anti-bot requirements.

## SEO and hosting

- Canonical site: `https://huygensoft.com`; configure `VITE_SITE_URL` if this changes.
- `huygensoft.uk` should serve the same Firebase deployment or redirect to the canonical `.com` domain at the DNS/Hosting layer.
- Firebase redirects legacy page and service URLs to the new locale routes.
- `static/` provides `robots.txt`, sitemap, manifest, favicon and social preview image. Company facts shown on the site are sourced from the [official Companies House entry](https://find-and-update.company-information.service.gov.uk/company/17250183).
